# 半岛铁盒 · Web Stylophone

浏览器里的迷你电子琴，灵感来自经典 Stylophone：按住滑动即可演奏，自带波形示波、音色预设，以及《半岛铁盒》等示范曲。

## 功能

- **触控 / 鼠标滑动演奏**：在琴键上按住拖动发声
- **电脑键盘演奏**：QWERTY 映射音符
- **MIDI 输入**：可连接外部 MIDI 设备
- **音色控制**：音量、波形（方波 / 锯齿 / 三角）、八度、颤音、弯音（Pitch Bend）
- **预设音色**：Classic Square、老式喇叭、电池不足、顺滑 ADSR、锯齿试听等，支持保存自定义音色
- **高级设置**：低通滤波、失真、噪声、电路底噪、ADSR、滑音、Hold、和弦模式
- **示范曲**：内置多首周杰伦风格旋律（含《半岛铁盒》《晴天》《七里香》等）
- **工具**：节拍器、随机音符、A4 参考音、旋律录制 / 回放、导出 MIDI 文本、录制 WAV
- **可视化**：波形与频谱实时显示

## 环境要求

- 现代浏览器（Chrome / Edge / Safari 等），需支持 **Web Audio API**
- Node.js 18+（仅本地开发需要）

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。首次发声需要用户手势（点击 / 触摸）以解锁音频上下文。

### 其他命令

```bash
npm run build    # 产出到 dist/
npm run preview  # 预览构建结果
```

## 演奏提示

1. 打开页面后点击任意控件或琴键，等待状态变为「运行中」
2. 在琴键区域按住滑动即可演奏；电脑端也可用键盘按键
3. 左侧 **BEND** 区域上下拖动可弯音
4. 需要更多音色细节时，点「高级设置」

## 技术栈

- Vite
- 原生 JavaScript + Web Audio API
- Web MIDI API（可选）
